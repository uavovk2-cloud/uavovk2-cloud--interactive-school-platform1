# Interactive School Platform

Перша статична демо-версія інтерфейсу інтерактивної шкільної платформи.

## Важливо
Ця версія призначена для перевірки дизайну та сценарію:
- учитель створює урок;
- отримує код;
- учень вводить код;
- відкривається екран уроку.

Це **не серверна багатокористувацька система**: демонстраційний код зберігається лише в браузері. Для реального уроку, де учні з різних телефонів бачать один і той самий стан уроку, наступним кроком потрібно підключити серверну частину (наприклад Cloudflare Workers + D1/KV або інший backend).

Файли `index.html`, `style.css` та `app.js` можна напряму розгорнути на Cloudflare Pages.
