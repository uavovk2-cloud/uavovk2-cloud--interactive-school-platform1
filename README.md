# Інтерактивна шкільна платформа

Поточна версія — **MVP реальної багатокористувацької платформи** для проведення уроків.

## Що вже є

- учитель створює урок;
- система генерує 6-значний код;
- учні приєднуються з різних телефонів за кодом без реєстрації;
- учитель додає питання;
- підтримуються варіанти відповіді або відкрита відповідь;
- учитель запускає урок і перемикає питання;
- учні бачать поточне питання;
- відповіді зберігаються та відображаються в кабінеті вчителя;
- клієнти автоматично оновлюють стан уроку кожні 2 секунди;
- фронтенд і серверна частина розгортаються одним Cloudflare Worker.

## Архітектура

- `index.html`, `style.css`, `app.js` — клієнтська частина;
- `src/worker.js` — Cloudflare Worker API;
- `migrations/0001_initial.sql` — схема D1;
- `wrangler.jsonc` — конфігурація Workers + Static Assets;
- `.assetsignore` — не дозволяє публікувати серверні файли як статичні ресурси.

## Що потрібно для запуску

Потрібен Cloudflare D1 database, прив'язаний до Worker як binding `DB`. Після створення БД потрібно застосувати міграцію `migrations/0001_initial.sql`.

Поточний код спеціально повертає зрозумілу помилку, якщо `DB` ще не підключена, замість тихого переходу в демо-режим.

## Наступні етапи

1. Підключити D1.
2. Перевірити створення уроку з двох пристроїв.
3. Перевірити підключення 10+ учнів.
4. Додати повноцінні типи інтерактивних завдань.
5. Додати журнал результатів і статистику.
6. Додати матеріали уроку та завантаження файлів.
7. Додати безпечніший режим доступу вчителя та керування уроками.
